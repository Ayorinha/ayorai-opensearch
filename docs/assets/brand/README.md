# AYORAI ATTRACTOR — identidade visual

A identidade visual usa fundo preto puro (`#000000`) e tipografia clara. O dente-de-leão substitui intencionalmente a letra “I” em **AYORAI**.

## Arquivos e usos

- `ayorai-attractor-banner.png` — banner horizontal para o topo do README e documentação.
- `ayorai-attractor-icon.png` — ícone quadrado de 512×512 px, destinado a avatar e ícone do projeto; **pendente de inclusão**.
- `ayorai-attractor-social.png` — imagem horizontal 1280×640 px para uso manual como prévia social; **pendente de inclusão**.

## Regras de aplicação

- Não distorcer as proporções nem recolorir a arte.
- Não separar o dente-de-leão do nome no banner.
- Em tamanhos reduzidos, confirmar que AYORAI continua legível e que a flor é reconhecida como o “I”.
- A imagem social é apenas um recurso pronto para uso. A prévia social do GitHub não é configurada por este commit; o mantenedor deve defini-la em **Settings → Social preview**.
