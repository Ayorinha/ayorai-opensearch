# AYORAI ATTRACTOR v0.6.0 — rascunho de notas de versão

**Status:** RASCUNHO — não é uma release publicada. Nenhuma tag ou release deve ser criada com este arquivo sem autorização explícita do mantenedor.

## Resumo

Esta proposta de release consolida melhorias de documentação, reprodutibilidade, avaliação e governança. O trabalho reforça a distinção entre regras metodológicas aprovadas, evidência sintética e resultados empíricos que ainda dependem de pessoas.

## Destaques propostos

- DEC-017 a DEC-020 registradas por emendas datadas: integridade de registros, partição confirmatória oculta, bootstrap por cluster de artigo e concordância humana.
- Executor RGC com partição explícita e intervalos primário/sensibilidade; a partição pública permanece descritiva.
- Ferramenta de concordância entre anotadores com Cohen's kappa não ponderado, IC95%, matriz de confusão, marginais por classe e exclusões RULE_GAP auditáveis.
- Reprodução controlada do contrato de corpo JSON null: nenhuma combinação FastAPI/Pydantic testada justificou impor limite adicional de dependência.
- Mais testes para o registry de plugins e caminhos de erro do provedor OpenAI-compatible; mypy estrito ampliado para os dois módulos de avaliação.
- Documentação técnica ampliada para operação, segurança, reprodutibilidade, avaliação, auditoria e governança.

## Compatibilidade e segurança

- A reprodução de JSON null não alterou a fixture congelada nem o comportamento da API.
- A matriz de dependências testada não identificou limiar de versão que justificasse alterar o pyproject.
- O CI de segurança não identificou vulnerabilidades conhecidas via pip-audit; os avisos restantes de parsing do Bandit foram tratados.
- Este rascunho não propõe remoção de rotas nem mudança de contrato HTTP.

## Limitações e itens não incluídos

- O protocolo RGC continua **[PROPOSTO]**, não congelado.
- Nenhum caso de piloto/benchmark foi criado, completado ou rotulado nesta etapa.
- Nenhuma execução do ATTRACTOR sobre casos RGC ou métrica de benchmark foi produzida.
- A calculadora de concordância foi testada apenas com dados sintéticos; não há anotação humana processada.
- Piloto 02, segunda anotação independente, revisão humana independente F-01 e decisão de congelamento continuam pendentes.
- Não há alegação de certificação, validação institucional, revisão independente ou prontidão para produção.
