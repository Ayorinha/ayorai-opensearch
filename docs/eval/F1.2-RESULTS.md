## Interpretation (decision rules of PREREGISTRATION-F1.2 §5)

- **Golden v0:** balanced accuracy unchanged (42.73% → 42.73%); McNemar p = 1.0. **Not improved.** H1.2 (candidate ≥ baseline, no new error in `conflict-negation`/`conflict-date`) holds.
- **Golden v0.1:** balanced accuracy unchanged (48.18% → 48.18%); McNemar p = 1.0. **Not improved.** H1.2 holds.
- No regression: no case that v4 got right is wrong in v5, in any category.
- Path C remains below the 43.33% majority baseline in accuracy on both suites.
- Every changed prediction moved from a wrong `REFUTED` to a still-wrong `UNVERIFIED`; none became correct. Macro-F1 rose (v0 0.2708 → 0.3258; v0.1 0.2992 → 0.4066) as a side effect, but macro-F1 is secondary and is not used to claim improvement.

## Consistency check (§5)

- **v0.1:** baseline v4 accuracy 33.33% matches the published E1 path C value (33.33%, 10/30). ✔
- **v0:** baseline v4 accuracy is **23.33%**, while the F1 table reports **26.67%** for path C. ✘ The F1 value was measured at commit `c4b73f4` (2026-10-03). Between that commit and the baseline `d245e68`, the rule detector was changed by the F1.1 numeric-fact rewrite (`0b6ab99` … `a31c9ef`) and by the provenance/GAP B fixes (`de9b83a`, `68c5d28`, `2bbfd31`, `a8ab5f3`, `8f2e34e`). The 26.67% therefore describes older code; with current code, before and after PR #111, path C scores 23.33% on Golden v0. Per §5, nothing was re-run to reconcile the two numbers. Documents that cite 26.67% as the current path C v0 accuracy should be updated to cite 23.33% with this note.

## Exploratory observations (not pre-registered; no claim is based on them)

- Wrong `REFUTED` verdicts fell from 1 to 0 on v0 and from 4 to 0 on v0.1. For a verifier, wrongly refuting a claim is a costly error, so this is a qualitative change worth tracking in future pre-registered measurements.
- Path C returns `UNVERIFIED` for 24/30 (v0) and 20/30 (v0.1) cases. Its dominant failure mode is abstention, not wrong polarity; the #111 fixes could not move accuracy because most cases never reach a supporting/contradicting decision.
- These observations are from development sets the author has inspected and must not be used to tune rules. Generalization remains reserved for the hidden Golden v1.
