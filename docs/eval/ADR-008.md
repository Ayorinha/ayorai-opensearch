# ADR-008 — AYORAI-PT-NLI: NLI comercial para português

- **Status:** Proposed
- **Date:** 2026-10-04
- **Priority:** Principal
- **Scope:** design only; **no training authorized by this ADR**
- **Related:** ADR-002, E1/E2/E3, ADR-007

## Context

E3 showed that unsupported-span detection does not solve source conflict. The primary missing capability is claim-level multilingual stance in Portuguese.

AYORAI-PT-NLI is therefore the **principal** Portuguese path and the commercial replacement for the current Path A dependency. The model must classify a claim against evidence into three semantic classes: SUPPORTS, CONTRADICTS, NEUTRAL.

The final ATTRACTOR verdict remains outside the model and is still produced by the deterministic Judge.

## Decision

### 1. Base model

Propose fine-tuning **EuroBERT-210m** with a 3-class sequence-pair classification head.

Requirements:
- Apache-2.0 model licence, verified from the primary model repository before training;
- Portuguese included in the model's supported languages;
- maximum context of 8,192 tokens;
- frozen model revision recorded before any training;
- no model release until the resulting weights and training data have an explicit commercial-license audit.

Primary model reference: https://huggingface.co/EuroBERT/EuroBERT-210m

### 2. Target contract

Input: claim + evidence

Output: SUPPORTS | CONTRADICTS | NEUTRAL

The model is a **stance classifier**, not the final Judge.

It must not emit final ATTRACTOR verdicts. Those remain governed by the deterministic Judge and ADR-002.

### 3. Training data — commercial-first

Training data must satisfy the repository's commercial-use policy before it enters the training set.

#### A. Synthetic Portuguese data from Brazilian official texts

Generate Portuguese NLI examples from public Brazilian official materials, including federal and state laws and regulations; **normas de reguladores do sistema financeiro e do mercado de capitais**; and judicial decisions and other official public decisions where the source terms permit the intended use.

The synthetic generator must be an Apache-2.0 model with a frozen revision. Candidate: Qwen/Qwen2.5-7B-Instruct; its primary model card identifies an Apache-2.0 licence. https://huggingface.co/Qwen/Qwen2.5-7B-Instruct

Generate balanced examples for direct support, explicit contradiction, unrelated/neutral evidence, numerical contradiction, entity mismatch, temporal contradiction, negation, and partial-overlap cases.

Each record must preserve: official source URL; retrieval date; source hash; source licence/provenance status; generator model and revision; prompt hash; seed; generated claim/evidence hashes; deterministic label-generation rule.

Synthetic labels are training labels, not external ground truth. A deterministic validator plus sampled human review is required before inclusion.

### 4. Copyright/legal gate

The working legal assumption is that Brazilian Law 9.610/1998, art. 8º may exclude certain normative/legal texts from copyright protection, but this must be **confirmed with qualified Brazilian counsel before commercial training**.

Until that confirmation, official legal/regulatory texts are not automatically classified as unrestricted training material; each source family requires a documented provenance/legal decision; ambiguous material is EVAL_ONLY; and no claim of legal clearance is made by this ADR.

This ADR is an engineering design, not legal advice.

### 5. Additional NLI datasets

External NLI datasets may be used only when a **primary source explicitly permits commercial use** and the exact version/revision is frozen.

Required record per dataset: dataset name/version; upstream URL; licence text; commercial-use determination; date checked; content manifest/hash; transformations performed.

**Explicitly excluded from training:** XNLI; ANLI; any dataset with unclear commercial rights; any dataset whose licence permits research-only/non-commercial use.

### 6. Data construction and leakage controls

- Split by source document, not by generated pair.
- Keep all variants derived from one source in the same split.
- Do not use Golden v0 or Golden v0.1 as training data.
- Hidden Golden v1 remains completely isolated.
- Golden v1 must contain Portuguese documents and Portuguese claim/evidence pairs.
- Freeze dataset manifest and SHA-256 before training.
- Record every transformation and license decision.

### 7. Training plan — future only

No training is performed by ADR-008.

Proposed Kaggle execution: build and license-audit the source manifest; generate Portuguese synthetic pairs with frozen Apache-2.0 generator; run deterministic validation and human sampling; load EuroBERT-210m; train a 3-class classification head; use deterministic seeds and reproducible configuration; evaluate by source family and semantic category; select operating policy only on development data; never tune on Golden v1; export model, tokenizer/config, dataset manifest, hashes, metrics and reproducibility metadata.

### 8. Evaluation — Golden v1

The decisive validation target is **Golden v1 with Portuguese documents**.

Required measurements: accuracy; balanced accuracy; macro-F1; per-class precision/recall/F1; confusion matrix; bootstrap IC95%, 10,000 iterations, seed 20261003; ECE/calibration; p50/p95 latency; abstenção if the production policy introduces one; category breakdown for numerical, entity, temporal, negation, partial overlap and conflict.

The **primary comparator is Path B**, the current commercial candidate. **Path A is a secondary reference only and is EVAL_ONLY**; it must not be treated as the primary promotion baseline.

Promotion requires a **pre-registered paired test showing improvement over Path B**, with no regression on **NEUTRAL** or **CONTRADICTS**. The paired analysis must be frozen before the Golden v1 measurement.

### 9. Architecture

Primary future path: Claim -> Evidence -> AYORAI-PT-NLI -> SUPPORTS/CONTRADICTS/NEUTRAL -> Clusters -> Provenance -> deterministic Judge -> final verdict.

ADR-007 AYORAI-PT-span remains secondary, primarily for long-response unsupported-span analysis in F2.

### 10. Commercial boundary

The target is a commercially usable training recipe, not merely an academically reproducible experiment.

Before any training run: model licence is frozen and archived; every training dataset has a primary-source licence decision; synthetic generator is Apache-2.0; excluded datasets are enforced by manifest; official Brazilian text legal status is confirmed or the affected items remain EVAL_ONLY; all provenance is hashed.

## Risks

- Synthetic data may encode generator artifacts.
- Official-source copyright/public-domain assumptions may be legally incomplete.
- NLI labels can confuse partial support with contradiction.
- Long context can increase compute and latency.
- Source conflict requires careful evidence clustering and must not be collapsed into simple unsupported-span detection.
- A Portuguese Golden v1 must be genuinely held out to establish generalization.

## Consequence

AYORAI-PT-NLI becomes the principal Portuguese stance path, preserving the deterministic Judge as the final adjudicator.

**NLI class ≠ ATTRACTOR verdict.**

No training, model release, Golden v1 measurement, merge, release or promotion is authorized by this ADR alone.
