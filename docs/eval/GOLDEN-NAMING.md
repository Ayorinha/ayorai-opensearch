# Golden fixture naming reservation

**Date:** 2026-10-03

The public deterministic Judge smoke fixture is `evals/golden/judge-smoke.jsonl`.

The name **Golden v1** and the path `evals/golden/v1.jsonl` are reserved exclusively for the future hidden Portuguese Golden v1 evaluation set. Public smoke fixtures must not use that name.

This reservation is documentation only and does not modify the frozen F0 preregistration.
