# Evolution Engine

ATTRACTOR should continuously discover better technologies without silently rewriting production.

Lifecycle:

1. Discover papers, releases, models, tools, benchmarks and provider changes.
2. Identify a candidate capability.
3. Verify provenance and licensing.
4. Run security and compatibility checks.
5. Execute isolated experiments.
6. Benchmark against the current baseline.
7. Compare quality, safety, latency, cost and reliability.
8. Promote only through a controlled canary.
9. Roll back on regression.

Technology Radar states:

ADOPT, TRIAL, WATCH, REJECT, DEPRECATED.

The objective is continuous measurable improvement, not uncontrolled self-modification.
