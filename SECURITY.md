# Security Policy

## Scope

This repository is an engineering prototype. Security reports should focus on reproducible vulnerabilities in the code, dependency chain, authorization boundaries, data handling or tool execution.

Do not submit secrets, credentials, personal data or confidential institutional material.

## Reporting

Use GitHub's private vulnerability reporting mechanism when available. Include a minimal reproduction, affected version or commit, impact and suggested mitigation.

Generated AI output is not, by itself, evidence of a security issue; provide a reproducible technical condition.
